# Code of Conduct

## Our commitment

We are committed to a welcoming, respectful, and harassment-free community for
everyone, regardless of background, identity, experience, political belief, or
technical ability.

This project handles politically sensitive public records. Disagreement about
policy is expected; hostility toward contributors or the people represented in
the data is not.

## Expected behavior

- Discuss evidence, data, and code rather than attacking people.
- Assume good faith while still asking for verifiable sources.
- Be precise about uncertainty and correct mistakes openly.
- Respect privacy and avoid amplifying personal information beyond the project's
  legitimate public-interest purpose.
- Accept constructive feedback and help newcomers participate.

Harassment, threats, discriminatory language, deliberate misinformation,
doxxing, and sustained disruption are unacceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers through
GitHub's private vulnerability-reporting channel when available. Maintainers may
remove content or restrict participation when needed to protect the community.
Reports will be handled as confidentially as practical.

This code of conduct applies in repository spaces and when someone officially
represents the project elsewhere.
