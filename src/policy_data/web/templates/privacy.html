Privacy

Pochi dati, per poco tempo.

L’accesso usa un digest dell’indirizzo email, codici a scadenza, sessioni revocabili e chiavi API memorizzate solo come digest HMAC.

Cosa non conserviamo

Non memorizziamo password né il valore originale delle API key. I documenti parlamentari rimangono attribuiti alle fonti istituzionali.

Eliminazione

La cancellazione manuale dell’account e dei dati di accesso sarà disponibile dal dashboard prima dell’apertura pubblica.
